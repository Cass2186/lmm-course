# LMMs for Hypertrophy Trials

Interactive companion to a short course on linear mixed models, built with [Quarto](https://quarto.org) and [quarto-live](https://r-wasm.github.io/quarto-live/) (R running in the browser via webR).

Source pages are the `.qmd` files; the rendered site is in `docs/`. Rebuild with `quarto render`.
