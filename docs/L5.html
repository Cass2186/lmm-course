5 · Nesting, multiple outcomes and power

Images within visits, multiplicity, power by simulation and reporting

Course data (loads automatically; click to see the code)

R runs inside your browser. The first visit downloads R and the packages, which takes 20–40 seconds; after that the browser caches them. Wait for this block to finish before running exercises.

The ultrasound data have three layers: participants, visits within participants (day-to-day variation) and images within visits (measurement error). The matching model is

lmer(VL_CSA_cm2 ~ Group * Week_f + Sex + (1 | ID/Week_f), data = img)
# (1 | ID/Week_f) = (1 | ID) + (1 | ID:Week_f)

Averaging the images first gives the same answer when every visit has the same number of images and there are no image-level predictors. Leaving out the visit level, i.e. (1 | ID) on image rows, is pseudoreplication at the visit level.

Explore: power calculator

Simulate trials like this one (3 visits, random intercept) and estimate the power to detect a given difference in change at week 12. Defaults use the variance components from the course data. Each run fits nsim mixed models in your browser (100 simulations take about 30–40 seconds), so press Run Code when you’ve set the sliders.

viewof pw_n     = Inputs.range([6, 60], {value: 20, step: 1, label: "Participants per arm"})
viewof pw_delta = Inputs.range([0, 2], {value: 0.6, step: 0.05, label: "True difference in change (cm²)"})
viewof pw_sdres = Inputs.range([0.2, 1.2], {value: 0.61, step: 0.01, label: "Within-person residual SD"})
viewof pw_drop  = Inputs.range([0, 0.3], {value: 0.1, step: 0.01, label: "Dropout before week 12"})
viewof pw_nsim  = Inputs.range([50, 400], {value: 100, step: 50, label: "Simulations"})

Set the difference to 0 to check the Type I error: it should be close to 0.05. Then halve the residual SD and see how much power improves. Reducing day-to-day measurement noise (standardized scan conditions) is often cheaper than recruiting more people.

Exercises

Q1 — Nested, averaged and wrong

Nest visits in participants: (1 | ID/Week_f). Nested and averaged both give 0.990 (SE 0.282, df ≈ 71). The wrong model gives 0.994 with SE 0.159 and df ≈ 300: about 44% too small, because it treats day-to-day variation as if it were averaged over 3 independent visits.

Q2 — Where does the noise come from?

Divide by k. Participant SD ≈ 2.94, visit SD ≈ 0.58, image SD ≈ 0.35 cm². A visit mean has SD ≈ 0.67 with 1 image, 0.61 with 3 and 0.60 with 6. More images barely help because day-to-day variance dominates. A second baseline visit, or tighter pre-scan standardization, is the better investment.

Q3 — Secondary outcomes and multiplicity

method = "holm". Lean mass +0.16 kg (0.03 to 0.29), p ≈ 0.016 (Holm 0.032); 1RM ratio 1.026 (0.968 to 1.087), p ≈ 0.38. A fixed sequence CSA → lean mass → 1RM gives the same conclusions: Protein increased muscle size by two measures, with no detectable effect on strength.
